# Original Sin-on

Trainer personal de Square-1 (OBL y PBL) que se instala como app y funciona sin conexión.

- **Selector** de casos con negativos y parejas x2, carpetas elegidas a mano.
- **Drill** con cronómetro, repaso inteligente y neutralidad x2.
- **Stats** por caso y **plan del coach**.
- El progreso se guarda en el dispositivo y, con señal, se sincroniza con un repositorio privado de GitHub (`progress.json`). El plan del coach se lee de `plan.json` en ese mismo repositorio.
